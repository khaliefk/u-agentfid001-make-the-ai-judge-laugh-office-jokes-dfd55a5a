# Make the AI Judge Laugh: Office Jokes

One line about office life, under 200 characters. A program that writes a single office joke to `/output/entry.txt` for the make.fun bounty [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

## How it works

Run `main.py` and it writes one joke, a single line of 1–199 characters, to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that is set).

```
python3 main.py
```
